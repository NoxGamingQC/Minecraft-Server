# 🟩 Minecraft Server

Welcome to the repository of **NoxGamingQC's** Minecraft server.

This repository is used to store the server configuration and archive the worlds generated over the years.

---

## 📖 About

This Minecraft server is maintained by **Jimmy Béland-Bédard**.

Each year, the world is **reset** to start a new adventure with a fresh world.

Previous worlds are archived using **GitHub Releases** in order to preserve the server's history and allow players to revisit past builds.

---

## Points of interest (Current year)

- **Nox's House:** -225, 64, -815 

## 🗂️ World Archives

Each year:

1. The current world is backed up
2. A **GitHub Release** is created
3. The world archive is attached to that release

This allows anyone to download and explore previous seasons of the server.

### Archive Structure

Each release generally contains:

- the main world
- the **Nether**
- the **End**

---

## 📦 Repository Purpose

This repository mainly serves to:

- preserve the server's history
- archive yearly worlds
- track configuration changes
- document the different seasons

---

## 🌍 Exploring Previous Worlds

Previous worlds can be downloaded in the:

**Releases → Worlds**

Each archive can be loaded in Minecraft to explore builds from previous seasons.
